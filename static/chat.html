    About

    Syntrix AI

    Smarter. Deeper. Always Here.

    Syntrix AI is a private AI assistant that runs on your own computer. Its language models run locally through Ollama, so there are no subscriptions, no API fees and no accounts. It has three specialist modes, and each one uses the model and the knowledge source that suit its job.

    Three modes
    • AutoMobile: an automotive engineering assistant. It looks up answers in a curated knowledge base of automotive Q&A pairs (retrieval-augmented generation) before it replies.
    • Programming: a coding assistant for writing, explaining and debugging code.
    • General: an assistant for science, maths, history, technology and everyday questions. It searches the web and lists its sources under each answer, so you can check the facts.
    What it can do
    • Stream answers word by word as they are written
    • Save every conversation and keep a separate memory for each chat
    • Read attached PDFs, text files and code files, then answer questions about them
    • Let you choose answer length, switch web search on or off, and use light or dark theme
    Built with

    Python and FastAPI on the server, Ollama for the language models, ChromaDB with sentence-transformers for retrieval, SQLite for chat storage, and a custom HTML, CSS and JavaScript interface with no framework.

    Privacy

    The AI models run entirely on your machine, and your chats and files are stored locally. The only data that leaves your computer is the short search query sent to the web when General mode searches.

    Good to know

    Syntrix runs on a standard computer without a graphics card, so answers can take a little time, especially in General mode. Like any AI, it can make mistakes, so check important facts against the sources it lists.
